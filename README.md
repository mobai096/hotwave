# 🌊 Hot Wave - AI 视频创作助手

> 一句"帮做个视频"，剩下的交给热浪。

追热点、写脚本、找素材、配音、合视频——全自动。

## 安装

```bash
pip install hotwave
hotwave onboard
```

## 使用

```bash
hotwave
```

然后就像跟人聊天一样：

```
🎬 你: 今天有什么热点？
🌊 热浪: 微博那边XX爆了，B站在推YY，要我细说哪个？

🎬 你: 帮我把XX做个30秒科普视频
🌊 热浪: 好，我先搜搜素材……
```

## 功能

- 6 大平台热搜（微博/知乎/B站/百度/头条/抖音）
- AI 脚本生成（科普/震惊/沙雕/冷静分析）
- 素材搜索（Pexels 免费可商用视频）
- 多模态素材审核（AI 自己看画面合不合适）
- TTS 配音
- 视频合成
- 项目管理 & 版本控制
- 用户风格记忆

## 架构

```
热浪 = ReAct Loop（自研）
     + 多模态模型做"眼睛"
     + hot-daily 工具集
     + 记忆系统
     + 项目/版本管理
     + TUI 聊天界面
```
